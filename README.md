# SmartHome

A simple smart home application built with SwiftUI for controlling and managing connected devices.

## Overview

This project was created as part of my iOS development training. The application demonstrates a basic smart home interface where users can view and control different types of devices.

## Technologies

- Swift
- SwiftUI
- Xcode

## Features

- Displaying smart home devices
- Device-specific controls
- Support for different device types
- Interactive controls using SwiftUI
- Grid-based device layout

## Devices

The application includes examples of:

- Living room light
- Heating system
- Front door lock

## What I Practiced

- Building interfaces with SwiftUI
- Working with reusable views
- Using enums to represent device types
- Managing UI state
- Creating interactive controls
- Building layouts with SwiftUI
